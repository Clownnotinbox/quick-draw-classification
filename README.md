# Quick, Draw! — классификация рисунков

Решение соревнования Kaggle «Quick, Draw! Challenge (Autumn 2026)» на курсе «Компьютерное зрение» Центрального университета.
Нужно определить, что нарисовано на картинке. Всего 345 классов.

**Результат:** 0.777 accuracy на Kaggle. На отложенной части данных 0.781, у базовой модели 0.681.

## Решение

- **Данные.** 586 тыс. рисунков для обучения, 52 тыс. для выбора настроек (eval), 52 тыс. для последней проверки (test).
  Повторы и спорные метки убраны.
- **Модели.** ResNet18, ConvNeXt-Tiny и EfficientNetV2-S/M с весами ImageNet, последний слой заменён под 345 классов.
  Для сравнения есть маленькая сеть с частичными свёртками по идее FasterNet.
- **Обучение.** AdamW с плавным изменением learning rate, MixUp и EMA весов. Аугментации: поворот, сдвиг, отражение,
  другая толщина линий и лёгкое искривление рисунка.
- **Итог.** Вероятности шести моделей усредняются с весами. Веса, температура и TTA (отражение, сдвиг, поворот, масштаб)
  подобраны на eval. Готовое решение проверено на test.

## Файлы

- `draw.ipynb` — основной ноутбук: данные, модели, обучение, сравнение опытов и итог. Все ячейки уже выполнены.
- `run/log.csv` — лог обучения по эпохам, `run/choice.json` — выбранный ансамбль, `run/score.json` — итоговые метрики.
- `run/submission.csv` — ответ, отправленный на Kaggle.
- `read.txt`, `req.txt` — как запустить и версии библиотек.

Веса шести моделей (от 83 до 215 МБ каждая) и данные соревнования в репозиторий не входят: GitHub не принимает файлы
больше 100 МБ, а данные выдаёт Kaggle на странице соревнования.
